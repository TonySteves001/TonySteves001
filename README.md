### 🔐 How Cybersecurity Shapes My Engineering Approach
My cybersecurity background influences how I approach software engineering. I believe that effectively securing an application requires more than understanding vulnerabilities and security tools. It requires understanding how the application is designed, how its components interact, how its data flows, and how its underlying systems are engineered.

This is why I place importance on understanding software architecture, backend systems, APIs, databases, authentication, authorization, infrastructure, and application behaviour. By understanding how software is built, I can better understand how it can fail, where vulnerabilities can emerge, and how security can be integrated into the engineering process from the beginning rather than treated as an afterthought.
